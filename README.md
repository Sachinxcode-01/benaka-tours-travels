## 📌 Executive Summary

**Benaka Tours & Travels** is Gadag's most trusted **100% Chauffeur-Driven** vehicle rental service, operating continuous 24/7 luxury outstation, local, corporate, wedding, and pilgrimage transport across Karnataka, Goa, Maharashtra, Telangana, Andhra Pradesh, and Tamil Nadu since 2019.

This repository contains the enterprise-grade **React + TypeScript** web platform engineered with **Feature-Sliced Design (FSD)** architecture, smooth **Motion for React** dynamic micro-interactions, **MapLibre GL** live location mapping, and a full automated Vitest test suite.

## 🚀 Technical Architecture & Tech Stack

```text
src/
├── app/          # App initialization, global styles, providers, router configuration
├── pages/        # Route page components (Home, Fleet, Vehicle Details, Booking, Contact, Admin)
├── widgets/      # Compositional UI widgets (Header, TopBar, Footer, LocationMap, MobileActionBar)
├── features/     # Business capabilities (Hero, FleetPreview, InquiryForm, BookingWizard, Reviews)
├── entities/     # Domain data models & types (Vehicle, Business, FAQ)
└── shared/       # Reusable primitives, hooks, services, UI components (Button, Modal, Drawer, Map)
```

- **Framework**: React 19 + TypeScript + Vite v6
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Custom Obsidian & Gold Design System
- **Animation**: Motion for React (`motion`) + GSAP ScrollTrigger
- **Mapping**: `@mapcn/map` + `MapLibre GL` with CARTO & OpenStreetMap tiles
- **Icons**: `lucide-react`
- **Testing**: Vitest + React Testing Library + jsdom

## 🛠️ Local Development & Scripts

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Execute TypeScript typecheck
npm run typecheck

# 4. Run Vitest test suite
npm run test:run

# 5. Run Oxlint code linter
npm run lint

# 6. Build production bundle
npm run build
```
